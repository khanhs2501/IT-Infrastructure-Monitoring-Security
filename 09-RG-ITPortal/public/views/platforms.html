Trang này phân biệt đã cấu hình và kết nối được với chưa cấu hình. Kiểm tra TCP chỉ xác nhận cổng có thể truy cập, chưa chứng minh đăng nhập API thành công hay dịch vụ hoàn toàn khỏe mạnh.

Kubernetes (read-only)
Chưa kiểm tra

Cấu hình trong .env: K8S_API_URL, K8S_BEARER_TOKEN. API bắt buộc HTTPS; token nên thuộc ServiceAccount chỉ có quyền get/list nodes và pods. Không dán token vào chat hoặc lưu trong database Portal.

AWS EC2 / CloudWatch (read-only)
Chưa kiểm tra

Cấu hình bằng CLOUD_PROVIDER=aws, AWS_REGION, AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY và tùy chọn AWS_SESSION_TOKEN. Chỉ dùng credential/role có quyền đọc EC2 và CloudWatch; nên ưu tiên temporary credentials trong môi trường thật.

Không nhập thông tin bí mật ở giao diện này. Kết nối được truy vấn ở chế độ chỉ đọc; trang này không thay đổi firewall, node, pod, instance hoặc tài nguyên cloud.
